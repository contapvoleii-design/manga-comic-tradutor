# Manga & Comic Tradutor

Aplicativo web instalável (PWA) para importar páginas de mangá e quadrinhos, reconhecer texto com OCR, traduzir para português do Brasil e exportar a imagem.

## Estado atual
- Estrutura inicial do projeto.
- Próxima etapa: interface de importação, OCR, tradução e exportação.
- O OCR será executado no navegador com Tesseract.js.
- A tradução depende de um serviço externo e pode exigir configuração de uma API própria para uso estável.

## Executar
Abra `index.html` em um navegador moderno ou publique o repositório com GitHub Pages.

## Observação
Este projeto é uma implementação independente inspirada nas funções solicitadas; não inclui código proprietário, marca ou recursos internos do aplicativo de referência.
